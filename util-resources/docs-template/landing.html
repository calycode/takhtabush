For learners

Built around the study session

Everything in the app points at one thing: getting the next card right.

Decks that stay readable

Markdown definitions, images, audio, tags, folders, import, and export. The deck table stays scannable.

Six study modes

Flashcards, multiple choice, typed, cloze, two matching layouts, and mixed. The launcher only offers what the deck supports.

Progress you can act on

Accuracy, due counts, a two-week schedule, and the weakest cards first. The stats page tells you what to study next.

For builders

One Worker, no hidden service

The SPA, API, media proxy, MCP endpoint, OAuth provider, and cron job deploy together.

A scheduler you can audit

SM-2-inspired, deterministic, and versioned. Review events are append-only; learning state is derived and rebuildable.

MCP for agents

Curated tools, scoped API keys, OAuth for ChatGPT, and an audit row for every write. No arbitrary code execution.

Single tenant by default

The first account is the owner. Allow a small group with an allowlist, or pin the owner address from the start.

See it before you deploy it

Light and dark themes, keyboard-first study, and a dashboard that tells you what is due.
